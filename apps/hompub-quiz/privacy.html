Privacy Policy

Effective: Pilot — October 2026 Applies to HomPub Quiz, pilot quiz web app
The short version

HomPub Quiz holds a nickname, answer choices and a score for each student for the length of one lesson, on one small server we call the referee, and then deletes them. There are no accounts, no cookies, no analytics and no ads. HomPub itself sees nothing. The only lasting copy of a game is the results file the teacher downloads.

Everything below is the detail behind those sentences.

Information we collect

From students: a nickname (typed, or spun from a list of random two-word names — no real name is required or wanted), the answer chosen for each question, and the time each answer arrived at the referee.

From the teacher: the quiz content — questions, options and the correct answers — for the duration of the game, plus a random host token so the game can be resumed if the laptop drops off the network.

That is the full list. There are no accounts, no email addresses, no sign-in and no cookies. The pages set no advertising ID and include no analytics or crash reporting. The student page loads no third-party scripts and fetches no fonts from third parties: a classroom of phones talks to exactly one server, the referee.

Where it lives, and for how long

A game lives in one Cloudflare Durable Object — a small, single-purpose storage unit — in the Cloudflare data center nearest the teacher who created it. It holds the quiz (including the answer key), the game's settings and current phase, and one row per player: nickname, score, streak and the answers given. No IP addresses, no device details, no browser details.

One more thing exists outside the game, to stop someone creating thousands of empty games in a day: when a teacher creates a game, the referee keeps a one-way hash of that day's date and the teacher's IP address, with a count. The hash cannot be turned back into an address or linked to the same person on another day, it says nothing about students, and it is deleted within 48 hours.

It is deleted:

  • when the teacher confirms the results download at the end of the game, or
  • automatically after 2 hours without any activity, or 30 minutes after the podium if the teacher never confirms.

The only lasting copy is the CSV the teacher downloads: rank, nickname, score and the answer to each question. What the teacher does with that file is the teacher's responsibility, as with any class record.

On each student's phone, a random reconnect token sits in the browser's storage so a dropped connection can rejoin without losing the score. It identifies the phone to the referee for that one game only, and it is cleared when the game ends. The teacher's quizzes, and the PIN and host token of the current game, are kept in the teacher's own browser storage on the teacher's own device.

What HomPub sees

Nothing about any game. Request logging is switched off on the referee. No IP addresses, nicknames, quiz contents or scores are logged or forwarded to us. The only figures we see are the hosting provider's aggregate request counts, which say nothing about who played or what was asked.

What the app can access on your device

A web app asks the browser for access rather than installing permissions. Here is everything HomPub Quiz uses:

Yes — to the quiz referee only
Browser storage
Students: one reconnect token. Host: your own quizzes and the current game
Keep screen awake
Yes, during a game, so the phone does not lock mid-question
Camera
Not requested — QR codes are read by the phone's camera app, not the page

Not requested

Not requested

Not requested

Third-party services

Cloudflare hosts the referee. To route traffic it processes connection metadata — IP address and timing — under Cloudflare's own privacy policy, just as GitHub does for this website. HomPub does not receive that metadata.

No advertising network, no analytics SDK, no crash reporting service and no social-media widgets are included on any page.

Children's privacy

HomPub Quiz is built for classrooms, so most players are children, and the design starts from that. A student is known to the referee only by a nickname, which is never linked to an account, email address, device identifier or any other persistent identifier. Nothing is retained once the lesson ends. The teacher is the only person who ever holds a copy of the results.

Schools that want even the nickname-and-score data to stay entirely under their own control can deploy your own copy of the referee, because it is open source.

Fairness and timing

Answers are timed on the referee's clock, not the phone's, so nobody gains by changing their device's time. The flip side: a student on a slow connection may lose a few points per question in speed mode, because their answer takes longer to arrive. Teachers who want to remove that effect can run the game in accuracy mode, where every correct answer is worth the same.

Changes to this policy

This is a pilot, and the service will change. If it changes in a way that affects this policy — for instance, if a future version stores anything beyond what is listed here — this page will be updated first, and the "Effective" chip above will change accordingly.
