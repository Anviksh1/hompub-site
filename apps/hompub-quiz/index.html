HomPub Quiz

A live classroom quiz for one teacher on the projector and a room full of phones. Students join with a PIN and a nickname — no accounts, and nothing kept after class.

What it is

HomPub Quiz is a Kahoot-style live quiz. The teacher runs it from a laptop plugged into the projector; students answer on their own phones, a whole class at once. Students join by typing the 6-digit PIN from the big screen or by scanning its QR code.

Every question has up to four answers, and each answer slot is always the same shape in the same colour — red triangle, blue diamond, yellow circle, green square — so the game can be played by shape alone. Scoring is your choice: speed mode, where a faster correct answer earns more points (the Kahoot formula), or accuracy mode, where every correct answer is worth one point.

How it works

For the teacher

  1. Write the quiz. Type the questions on the host page, or write them in Word and upload the file (there is a template to download; pasting plain text works too). Each question has up to four options, a time limit and a point value. The quiz is saved in your own browser and nowhere else — the Word file is read on your laptop, not sent to a server.
  2. Start a game. A PIN and a QR code appear on the projector. Students join, and you watch the nicknames arrive. Press Start when the room is in.
  3. Run the questions. You control the pace: close, reveal, next. After the podium, press End game: the results file (a plain CSV) downloads to the laptop. Save it, confirm, and the referee forgets the game.

For students

  1. Go to the address on the projector, type the PIN, then type a nickname or spin a random one.
  2. Tap the shape that matches your answer before the timer runs out. Your own score and rank appear after every question.

Features

  • No accounts
  • Nickname only
  • Wiped after class
  • Open source
  • Up to 250 players
  • Works on any phone browser

Run a quiz

Open the host page

Students open hompub-quiz.vaidyadeenadayal.workers.dev on their phones and type the PIN shown on the projector — there is nothing to install and no account to make. HomPub Quiz is a pilot: a small number of classes are trying it first.

The referee — the small server that keeps score — is open source. You can read the code or deploy your own copy.

Works where ordinary HTTPS works

HomPub Quiz needs nothing more than a normal secure web connection. Wherever a phone can load an ordinary website, it can join a game. The one catch: the game itself is a live connection that stays open for the whole lesson, and some school networks block or drop those. The host page runs a quick network check before you start, so you find out in the staff room rather than in front of the class. If the check fails on the school Wi-Fi, ask IT to allow live (WebSocket) connections to the quiz address.

Privacy

No student accounts. Students type a nickname or spin a random one. A small open-source referee holds nicknames and scores for the length of the lesson, then forgets them. The only lasting copy is the results file the teacher downloads.

No sign-in, no cookies, no analytics, no ads, and no third-party scripts on the student page. The full policy says exactly what the referee holds, where, and for how long.
